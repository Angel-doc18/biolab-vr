For parents

Know how revision is going, every week

Create a free parent account and link it to your child with the code shown in their app. Every week you get a report: time spent, topics finished and scores, with the topic that needs a word of encouragement.

  • Free, on your own phone
  • A report every week
  • A message if revision stops for three days

For schools

A school licence for every student

A school pays once and receives a code for each student. Students type their code in the app and Klass8 opens for the time the school paid for, with no mobile money needed at home.

  • One code for each student, for a term or a year
  • Teachers follow each class from their own phone
  • Prices agreed with each school
